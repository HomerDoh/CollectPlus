# Collect+

> **开源、本地优先、防失效的跨平台社媒收藏管理 Chrome 扩展**
>
> 告别「你收藏的视频已消失」——把喜欢的视频和图文，安静地存进你自己的电脑硬盘，随时离线回看、分类与检索。

---

## 为什么做 Collect+？

你一定遇到过这些烦恼：

- 刷到很棒的教程、灵感或美食做法随手点了收藏，过几个月想用时，只剩一行冰冷的 **「作品已删除 / 仅作者可见」**；
- 收藏分散在抖音、B 站、小红书等不同平台，想找一条看过的干货，翻半小时也找不到；
- 很多下载工具需要安装复杂的本地后端、命令行或第三方客户端，既折腾又担心隐私泄露。

**Collect+** 的思路很简单：**装一个纯浏览器插件就够了。** 无需任何后台服务、无需注册账号，你像平时一样刷网页点收藏，插件就在后台把无水印视频、原图和元信息静默保存到你指定的电脑文件夹里，并提供一套好用的本地知识库管理界面。

---

## 核心特性

- **无感收藏，双轨触发**：在抖音网页版点击原生「收藏」按钮即可自动捕获；也支持快捷键 **`Alt + S`**、页面左下角悬浮按钮或插件弹窗手动一键收藏。
- **高清无水印，支持视频与图集**：自动挑选兼容播放的高画质无水印 MP4 视频，以及图文笔记的全部原图与封面。
- **真正保存在自己硬盘**：所有内容按 `平台 / 年月 / 日期_ID_标题` 整齐归档在你指定的本地目录（`CollectVault`）中，人类可读、不锁格式、跨盘符可迁移。
- **离线播放与多图画廊**：在管理台内直接离线播放本地视频、键盘翻看高清图集，即使断网或原作品被删除也不受影响。
- **知识库级整理与搜索**：支持无限级文件夹树、自定义彩色标签、个人笔记备注，以及针对标题、正文、作者、标签和备注的中英文全文实时搜索。
- **不怕丢数据，一键重建索引**：换电脑、重装浏览器或清理浏览器缓存后，只要本地 `CollectVault` 文件夹还在，重新绑定并点击 **「重建索引」**，所有条目、分类和标签都能 100% 恢复。
- **纯本地、零上传**：没有任何云端服务器，不收集也不上传你的浏览或收藏数据，一切完全由你掌控。

## 快速上手

### 1. 构建插件

环境要求：**Node.js 20+** 与 **pnpm**（推荐使用 Chrome 120+ 浏览器）。

```bash
# 1. 安装依赖
pnpm install

# 2. 构建生产版本
pnpm build
```

构建完成后，扩展产物位于项目的 `.output/chrome-mv3/` 目录中。

### 2. 加载到 Chrome

1. 在 Chrome 地址栏打开 `chrome://extensions/`；
2. 打开右上角的 **「开发者模式」**；
3. 点击左上角 **「加载已解压的扩展程序」**；
4. 选择本项目下的 `.output/chrome-mv3` 文件夹即可完成安装。

### 3. 开始使用（4 步走通）

1. **绑定本地收藏库目录**：点击浏览器右上角的 Collect+ 图标 → **「打开 Collect+ 全屏管理台」** → 点击顶部 **「选择 / 初始化 CollectVault 目录」**，在电脑上选一个你想存放收藏的空文件夹。插件会自动生成说明文件与初始结构。
2. **刷抖音顺手收藏**：打开 [抖音网页版](https://www.douyin.com/)，正常点击作品的 **原生收藏按钮**，或直接按 **`Alt + S`**（也可点击页面左下角的悬浮按钮）。
3. **随手归类**：右上角会弹出不挡视线的轻提示卡片，显示后台下载进度；你可以直接在这里选择文件夹、新建分类或加标签，也可以不管它继续刷，几秒后自动收起。
4. **同步落盘与离线回看**：平时浏览时下载的媒体会先静默暂存在浏览器内部（不弹权限框打扰你）；打开管理台后，点击 **「同步到 CollectVault」**（授权后也会自动静默同步），文件就会写入你选定的硬盘目录，随时搜索与离线播放。

## 本地收藏库目录结构（`CollectVault`）

你绑定的本地文件夹会自动保持如下整洁结构：

```text
CollectVault/
├── README.txt                                  # 自动生成并守护的目录说明与防误删提示
├── .collect-vault.json                         # 收藏库基础配置
├── taxonomy.json                               # 你的文件夹树与标签体系
├── items/
│   └── douyin/
│       └── 2026-11/
│           └── 20261123_7419283712_安全截断标题/
│               ├── meta.json                   # 该条目的标题、作者、标签、备注等元信息
│               ├── cover.jpg                   # 封面原图
│               ├── video.mp4                   # 无水印视频原件（视频类）
│               └── media/                      # 全部原图（图集类）
│                   ├── 01.jpg
│                   └── 02.jpg
└── .trash/                                     # 回收站归档目录
```

> **温馨提示**：请不要手动重命名、移动或删除 `CollectVault` 内部的零散文件，以免造成索引失效。如需迁移到其他盘符或新电脑，只需把 **整个 `CollectVault` 文件夹完整拷走**，再在 Collect+ 管理台重新绑定并点击 **「重建索引」** 即可。

## 常见问题（FAQ）

**Q：为什么重启 Chrome 后，管理台提示我再点一次「授权访问」？**
A：这是 Chrome 浏览器针对本地文件权限的安全保护机制（File System Access API 每次重启浏览器后需要你确认一次授权）。平时刷抖音时完全不需要授权弹窗，媒体会先静默暂存在浏览器私有空间（OPFS）中；等你打开管理台点一次授权，插件就会把积攒的内容一次性批量落盘到硬盘。

**Q：这插件需要安装 Python、FFmpeg 或桌面客户端吗？**
A：完全不需要。Collect+ 是 100% 纯 Chrome Manifest V3 扩展，流式下载、防盗链请求头处理、缩略图生成乃至后续的音视频无损混流，全部在浏览器扩展内部原生完成。

**Q：如果我误清空了浏览器数据，收藏的视频会丢吗？**
A：只要已经同步到本地 `CollectVault` 文件夹，**绝对不会丢**。重新打开管理台绑定原目录，点一下 **「重建索引」**，所有视频、图集、分类树、标签和备注都会原样恢复。

## 开发与参与贡献

### 技术栈一览

- **扩展框架**：WXT + Vite + React 19 + TypeScript（`strict` 模式）+ Tailwind CSS v4
- **本地存储与检索**：Dexie.js（IndexedDB）+ MiniSearch（中英文分词全文检索）+ OPFS + File System Access API
- **媒体下载与封装**：Offscreen Document 流式 `fetch` + `declarativeNetRequest` 会话级防盗链 + Mediabunny

### 常用开发命令

```bash
pnpm dev      # 启动热更新开发模式
pnpm compile  # 运行 TypeScript 严格类型检查
pnpm build    # 构建生产包至 .output/chrome-mv3/
pnpm zip      # 打包发布用 zip 归档
```
